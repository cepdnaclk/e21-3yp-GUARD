Core Capabilities

Six Reasons G.U.A.R.D Stands Apart

Purpose-built for aquaculture operations — every feature answers a real-world problem that costs fish health and money.

🌡️

Five-Parameter Sensor Fusion

Simultaneous real-time measurement of Temperature, pH, TDS, Turbidity, and Water Level via SVG arc gauges — zero polling lag with WebSocket push every 30-second cycle.

🔔

Triple-Channel Instant Alerting

Threshold breaches trigger simultaneous WebSocket toast, SMTP email, and Telegram Bot notifications — with in-memory throttling to prevent duplicate flood storms.

🎨

Glassmorphic Dual-Mode UI

"Milky Frost" and "Obsidian Glow" themes — backdrop-blur glassmorphic cards, Outfit typography, JetBrains Mono for telemetry, and smooth micro-animations throughout.

🐟

Fish Species Knowledge Base

20 research-verified freshwater species with optimal pH, Temp, TDS, and Turbidity ranges. Tank Compatibility Checker cross-validates threshold configs in real time.

🗺️

Guided Onboarding Tour

First-time users are never shown an empty dashboard — auto-routed to a /demo sandbox with driver.js step-by-step tour across 7 (USER) or 11 (ADMIN) highlights.

🔒

Enterprise Security Layer

Three-tier RBAC (SUPER_ADMIN / ADMIN / USER), bcrypt device secrets, JWT-protected REST, duplicate-alert suppression, and offline threshold sync via MQTT retained messages.

Real-Time Telemetry

Live sensor readings. Zero delay.

Each ESP32 node publishes a JSON payload to HiveMQ Cloud MQTT every 30 seconds. The backend authenticates with bcrypt, stores state in MongoDB, and writes time-series history to InfluxDB simultaneously.

  • ✓ DS18B20 waterproof digital temperature (OneWire)
  • ✓ Gravity pH-4502C Sensor — 6.5–8.5 safe range
  • ✓ JSN-SR04T ultrasonic water-level (non-contact)
  • ✓ Optical turbidity — TSS light-scattering, 50 NTU threshold
  • ✓ Analog TDS probe with temperature-compensated firmware

Alert Engine

Never miss a critical event.

The rule-based alert engine checks every telemetry payload against per-device configurable thresholds. If a breach is detected and no identical unresolved alert exists, an Alert record is persisted and dispatched across all channels simultaneously.

  • ✓ WebSocket push → instant React toast notification
  • ✓ SMTP email delivery to tank owner on breach
  • ✓ Telegram Bot message via @GUARD_yp_bot
  • ✓ Per-account email / Telegram enable toggles
  • ✓ In-memory throttling prevents alert flood storms

Operational Pipeline

7-Step Data Journey

From sensor voltage to dashboard update — every stage in the real-time telemetry pipeline.

1
🔩
aquamonitor/devices/<uid>/data

ESP32 Sensor Acquisition & MQTT Publish

ESP32 reads DS18B20, pH, TDS, turbidity, and water level every 30 s. Serializes as JSON with device UID and bcrypt device secret, published to HiveMQ Cloud over TLS.

2
📡
MQTT Client Ingestion

Backend Ingestion & Device Authentication

Node.js MQTT client subscribes to the wildcard topic, extracts device UID, validates against MongoDB device registry, and verifies device secret with bcrypt. Unauthorized payloads are silently discarded.

3
🗄️
Prisma ORM + InfluxDB Write

Dual-Database Persistence

Latest-state fields updated in MongoDB via Prisma ORM. A time-series data point is simultaneously appended to InfluxDB water_quality measurement for historical charting.

4
⚠️
Alert Engine Rule Evaluation

Per-Device Threshold Check

Alert engine evaluates all 7 configurable alert types (TEMP_HIGH/LOW, PH_HIGH/LOW, TDS_HIGH, TURBIDITY_HIGH, WATER_LEVEL_LOW). On breach with no existing unresolved duplicate, an Alert record is persisted.

5
🔔
WebSocket · SMTP · Telegram

Multi-Channel Alert Dispatch

New alerts broadcast via socket.io (React toast), formatted SMTP email to tank owner, and Telegram Bot message to verified admin chat ID via @GUARD_yp_bot — all respecting per-user enable toggles.

6
💻
React + socket.io-client

React Dashboard Real-Time Update

Frontend listens on sensor_data and alert WebSocket events. SVG arc gauges re-render, alert badge increments, toasts appear — no refresh or polling needed.

7
📊
InfluxDB → Recharts

Historical Analytics via Sensor History Page

JWT-authenticated REST queries retrieve InfluxDB time-series and render interactive Recharts line graphs with a custom glassmorphic date-range picker for per-tank parameter history.
